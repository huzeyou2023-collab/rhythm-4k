# rhythm-4k

4K 触屏下落音游，单文件 HTML，零依赖，优先适配 iPad 横屏。

## 玩

直接打开 `index.html`，或访问 GitHub Pages。

- 4 条轨道，音符落到白线时点击对应轨道位置
- 键盘 `D F J K` 对应四轨，支持多点触控与鼠标
- 判定：PERFECT ≤60ms / GREAT ≤120ms / GOOD ≤200ms，超出记为 MISS 并断连击
- 谱面 830 个音符，约 4 分 12 秒，三段难度递进（前段舒缓、中段加密、末段回落）
- 结束显示分数、最高连击、准确率与四档判定统计

## 实现要点

- 音符位置由时间差换算（`y = 判定线 - (音符时间 - 当前时间) × 像素/秒`），帧率波动不影响判定
- 谱面时间轴连续累加，无相位跳变
- 判定线、轨宽、速度在 resize / 转屏后重算
- 切后台自动补时，不吞进度

## 已知边界

- 无背景音乐，节奏全靠视觉与点击音效；要接真实曲子需另做 BPM 对齐
- 谱面每次随机生成，不固定
